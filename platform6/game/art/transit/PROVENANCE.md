# Authored transit / moonlit overlook presentation

The night_view.svg illustration and all geometry in world/transit_presentation.gd are original project-authored assets. No downloaded, paid, or generated-service assets are used. Geometry is procedural and editable in source. The pass reuses the project's original apartment wood/plaster/cloth SVGs and station painterly atlas. All new assets are original project work, supplied for commercial use with this source; no third-party asset license applies. see ../apartment/PROVENANCE.md and ../../ASSET_LICENSES.md.

All new scenery is static, collision-free and has no story actions. The original water shader and reduced-motion preference route are retained.
