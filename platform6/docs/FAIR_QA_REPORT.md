## Limits
No physical controller, sound-hardware listening, hardware GPU, Windows/Web runtime, macOS, Android/iOS or store-readiness acceptance is claimed. Driver VSync changes are unsupported; graphical tests explicitly select Dummy audio because the cloud desktop lacks an audio output device. Source import uses writable HOME and all XDG directories; earlier environment-only cache errors were corrected before the final clean suite.
